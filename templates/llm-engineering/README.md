# Domínio opcional de LLMs

Copie `.apos/domains` e `.apos/llm` para o consumidor; adapte ownership e integrações. Registre `llm_engineering` no ContextProfile e EpistemicRegistry. Defina metas e budget antes de executar. Campos nulos mantêm o experimento não elegível. Não copie resultados de um consumidor como evidência geral. Consulte [arquitetura](../../docs/architecture/LLM_ENGINEERING.md).
